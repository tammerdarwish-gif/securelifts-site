## Authority Flywheel

The goal is to make every public profile help the next one:

1. Accurate listings create search and map trust.
2. Listings send leads to tracked website URLs.
3. Website forms send clean source data into GHL.
4. GHL keeps sales follow-up, review requests, and service-plan nurture organized.
5. FieldPulse keeps the job and service record clean.
6. Completed jobs create reviews, photos, referrals, and stronger listings.
