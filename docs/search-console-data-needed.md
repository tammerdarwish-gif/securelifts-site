# Search Console and Business Data Needed

Mass consolidation remains blocked on evidence, not code capability. Export the following before deciding which of the hundreds of local pages survive.

## Google Search Console — last 16 months

- Performance by page and query, including clicks, impressions, CTR and average position.
- Country and device breakdowns.
- Page indexing: indexed, crawled-not-indexed, discovered-not-indexed, duplicates, alternate canonicals, soft 404s, 404s and redirects.
- Sitemaps, internal links, external links, Core Web Vitals, Manual Actions and Security Issues.

## Analytics and operations

- GA4 landing pages and conversions.
- Telephone and form conversions with deduplication confirmed.
- FieldPulse leads, booked jobs, sold jobs, completed revenue and lead source.
- Revenue by landing page, service and city.
- Backlink export with target URL and referring-domain quality.

## Classification rule

Use the inventory CSV as the technical base, then assign `KEEP`, `IMPROVE`, `POTENTIAL_MERGE`, `POTENTIAL_REDIRECT`, `POTENTIAL_NOINDEX` or `MANUAL_REVIEW` using performance, leads, revenue, backlinks and genuine local proof. Do not make removal decisions from word similarity alone.
