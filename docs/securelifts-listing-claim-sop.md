## Platform Workflow

For each platform:

1. Search for an existing SecureLifts profile before creating a new one.
2. If a correct profile exists, claim it.
3. If an incorrect profile exists, claim it and fix the data.
4. If no profile exists, create it using the standard profile details.
5. Use `Garage Door Supplier` as the primary category when available.
6. Add supporting categories only if the platform allows them.
7. Add the tracked URL from the listing tracker.
8. Upload logo and job photos when the platform allows images.
9. Save the live profile URL in the tracker.
10. Mark the completion status.

## QA Checklist

Before marking a profile complete:

- Public name shows `SecureLifts`.
- Phone shows `(866) 828-1818`.
- Address matches `8570 NW 70th ST., Miami, FL 33166` unless the platform is set to service area only.
- Website or booking URL is correct.
- Primary category is `Garage Door Supplier` when available.
- Description does not show `AAA Garage Door Inc.` as the public name.
- No paid upgrade was selected.
- No customer messages were sent.
- No ads were activated.
- Profile URL is saved in the tracker.
- GHL source tag exists or is planned for that platform.

## Stop Points

Stop and wait for owner action when a platform asks for:

- Password.
- Email verification code.
- Phone verification code.
- CAPTCHA.
- Payment.
- Subscription.
- Paid upgrade.
- Final public submission if there is uncertainty about the profile details.
